## 🚀 كيفية الاستخدام

### تحميل المشروع:
```bash
git clone https://github.com/ghabood267-design/crumble-co.git
cd crumble-co
```

### فتح الموقع:
افتح ملف `index.html` في المتصفح

### التعديل:
يمكنك تعديل الألوان من ملف `styles.css` بتغيير متغيرات CSS:
```css
:root {
    --primary-color: #D4A574;
    --primary-dark: #8B6F47;
    --accent-color: #C97A8A;
}
```
